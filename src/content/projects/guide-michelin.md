## Context

I built this as a redesign of the Guide Michelin website. The repository contains a Nuxt 4 application with Vue and TypeScript, styled with Nuxt UI and Tailwind CSS 4.

## What's inside

The project is a Nuxt site with a production build and a deployed preview. Its dependencies include Nuxt Image and VueUse alongside Nuxt UI. The source repository is [guide.michelin.com](https://github.com/rchrdkvcs/guide.michelin.com).

## Stack

Nuxt 4, Vue, TypeScript, Nuxt UI, Tailwind CSS 4, and Nuxt Image.
