## Context

I built Openlink as a self-hosted alternative for managing short links across personal and team workspaces. It supports the complete link lifecycle, from custom domains and QR codes to expiry rules and visit limits.

## What's inside

- Workspaces, members, folders, and tags
- Short links on the instance domain or verified custom domains
- Scheduled, expiring, password-protected, and visit-limited links
- Customizable QR codes and privacy-conscious analytics
- Email/password authentication, two-factor authentication, optional Google and Discord sign-in, user API tokens, and an HTTP API

## Stack

Laravel with Octane and FrankenPHP, Inertia.js, Vue 3, TypeScript, Tailwind CSS, PostgreSQL, Redis, and Docker.
